## 🕹️ How to play

- **Spacebar** or **click/tap** the game screen → flap upwards
- Avoid the green pipes and the ground
- Each pipe you pass = 1 point
- Crash → press **START** again to retry

---

## 🛠️ Run locally (no server needed)

1. Download `index.html` from this repository
2. Double‑click it – your default browser opens the game
3. Choose a hero and press **START**

That’s it. No Python, no C#, no command line.

---

## 🌐 Deploy your own copy on GitHub Pages

1. Fork this repository (or create a new one with the same files)
2. Go to **Settings → Pages**
3. Under **Branch**, select `main` and `/ (root)`
4. Click **Save**
5. After 1‑2 minutes, your game is live at:  
   `https://yourusername.github.io/repo-name/`

---

## 🧠 Code structure

- **`index.html`** – single file containing HTML, CSS, and JavaScript
- Uses Canvas API for graphics and requestAnimationFrame for the game loop
- No external dependencies (pure vanilla JS)
